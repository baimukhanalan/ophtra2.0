# Whitespace audit (find-only)

**Scope:** all 88 ru routes from `sitemap.xml`, tested at 390×844 (mobile, isMobile/hasTouch), 768×1024 and 1440×900. Chrome was driven by Playwright with `reducedMotion: 'reduce'`. Each page waited 3.5 s for the preloader, was scrolled through, then returned to the top before measuring.

**Method:** the script collects every visible content block (text, media, controls, and cards with a background or border narrower than 90 % of the viewport). It merges their vertical extents and flags any gap between consecutive blocks larger than 96 px on mobile, 128 px on tablet or 160 px on desktop. For each gap it walks the DOM up from the block above and down to the block below, listing each margin, padding, min-height or row-gap on the way. The same pass checks side-by-side columns with blank area, min-height slack, invisible-but-sized elements and empty containers.

**Totals:** 371 gaps on mobile, 367 on tablet, 414 on desktop. No page errors and no redirects.

- Scripts and raw data: `audit/jitter/_work/whitespace/` (`measure.cjs`, `results.json`, `agg.txt`, `shots.cjs`).
- Screenshots: `shot_d__laser-vision-correction_1800.png` (story chapters), `shot_d__science_8000.png` (hscroll band), `shot_d__doctors_dinara-omarova_2700.png` (empty reviews), `shot_d__laser-vision-correction_5900.png` (single-doctor team), `shot_d__diagnostics.png`, `shot_m__science.png`, `shot_t__about.png`.

## Checked and clean (not whitespace bugs)

- **Invisible elements taking space:** no reveal leftovers. The only element at opacity ≤ 0.05 is the decorative `svg.oph-swirl` (0.04, absolutely positioned inside the CTA band), so it takes no layout space. Everything else was revealed under reduced motion.
- **Decorative empty boxes:** `.oph-pagehero__grain`, `.oph-portrait__rings` and `.oph-footer__mark` are absolutely positioned and add no height.
- **Sticky columns:** the tall blank columns next to `nav.oph-article__toc` (40 pages), `.oph-story__visual`, `.ppl-history__aside`, `.oph-pt-formgrid__aside`, `.oph-kb-stickyhead` and `.oph-pt-needs__intro` are sticky by design. They only look empty in a full-page screenshot, not while scrolling. #2 shortens the story ones.
- **`/contacts`:** the map `svg` with `min-height: 300px` is intended.
- **Tablet page hero** (963 px on `/about`): the photo stacks under the text, so the height is real content, not padding.

## Recommended order

1. #1 token change, #3 CTA/footer padding and #2 story chapter clamp: three shared rules, about 70 % of all flagged whitespace.
2. #5 reduced-motion media query (a bug, one line) and #8 empty sections (a data-driven fix in the TSX).
3. #4, #6 and #11 as polish, then compare against Figma.
